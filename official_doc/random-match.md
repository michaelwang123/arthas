# 随机配对

中文 | [English](random-match.en.md)

> 加密版 Omegle — 无注册、端到端加密、阅后即焚的随机聊天体验。

---

## 功能概述

随机配对（Random Match）是 Arthas 的匿名加密聊天功能，定位为**加密版 Omegle**。用户无需注册，系统自动将两个陌生人配对到一个端到端加密的临时房间中。所有消息阅后即焚，服务器零知识 — 既不存储聊天内容，也不保存用户身份。

核心体验：

- 无注册、无账号 — 点击即聊
- 全程 E2EE — 服务器仅中转密文
- 阅后即焚 — 房间过期后数据自动销毁
- 兴趣标签匹配 — 找到志同道合的人

---

## 配对流程

1. 用户点击 **Match** 进入匹配队列
2. 系统优先按兴趣标签配对（相同标签优先匹配）
3. 如果 10 秒内无标签匹配，降级为 FIFO 先到先得
4. 匹配成功后自动创建加密房间，双方进入聊天
5. 如果 60 秒内未匹配成功，提示超时并建议使用邀请链接

**冷启动降级：** 当队列中人数不足时，系统自动引导用户生成邀请链接分享给好友。

## 兴趣标签系统

兴趣标签帮助系统更精准地配对：

**预定义标签：**

| 标签 | 描述 |
|------|------|
| #tech | 技术讨论 |
| #music | 音乐爱好者 |
| #gaming | 游戏玩家 |
| #random | 随机话题 |
| #language | 语言学习 |
| #movies | 电影爱好者 |

**使用规则：**

- 最多选择 3 个标签
- 标签优先匹配：系统优先将具有相同标签的用户配对
- 10 秒降级：如果标签匹配超时，自动降级为 FIFO 模式

## 邀请链接（冷启动）

当队列中无人可配时，用户可以生成一次性邀请链接分享给好友：

**生成机制：**

- 点击 **Generate Invite Link** 按钮
- 系统生成包含唯一 token 的链接

**链接格式：**

```
{baseUrl}/match/{token}
```

**约束：**

| 属性 | 值 |
|------|-----|
| 有效期 | 5 分钟 |
| 使用次数 | 仅一次 |
| 过期行为 | 自动失效，需重新生成 |

对方打开链接后自动进入配对房间，无需在队列中等待。

---

## "Next" 连续会话

聊天结束后，用户可以点击 **Next** 按钮直接进入下一次配对，无需离开当前流程：

- 点击 Next 后立即重新进入匹配队列
- 系统自动排除刚配对过的对象，避免重复匹配
- 两次配对之间有 **10 秒冷却期**，防止滥用
- 冷却期间显示倒计时提示

---

## 房间延时（双方同意）

默认房间有效期为 30 分钟。如果双方希望继续聊天，可以通过延时机制延长房间寿命：

**触发条件：**

- 房间剩余时间不足 5 分钟时，系统自动弹出延时提示

**延时规则：**

| 规则 | 值 |
|------|-----|
| 触发时机 | 剩余 ≤ 5 分钟 |
| 操作方式 | 双方均点击 **Extend** |
| 每次延长 | 30 分钟 |
| 最大延长次数 | 3 次 |
| 最大总时长 | 2 小时 |

**注意：** 必须双方都点击 Extend 才能生效。单方面点击不会延长房间。

---

## 举报与拉黑

为维护社区安全，系统提供举报与拉黑机制：

**举报分类：**

- 骚扰 / 不当言论
- 垃圾信息 / 广告
- 冒充他人
- 其他违规行为

**处理机制：**

| 机制 | 说明 |
|------|------|
| 举报阈值 | 同一 IP 被举报 3 次触发封禁 |
| 封禁级别 | IP 级别 |
| 封禁时长 | 24 小时 |
| 生效时间 | 立即生效 |

举报后系统自动断开当前配对，将用户重新放回匹配队列。

## 安全模型

随机配对功能继承 Arthas 的零知识安全架构：

**密钥交换流程：**

1. **Client A** 在本地生成 AES-256 随机密钥
2. Client A 将密钥通过服务器中转发送给 Client B
3. **服务器仅中转**，不存储、不解析密钥内容
4. Client B 收到密钥后，双方使用该密钥进行 AES-256-GCM 加密通信

**安全保证：**

- **零知识** — 服务器无法解密任何消息内容
- **前向保密** — 每次配对生成新密钥，历史会话不可追溯
- **隔离性** — Match Room 不注册到 HubRegistry，不会出现在公开房间列表中
- **无降级** — 配对功能不会因任何原因降低加密等级

## 服务器配置

以下参数可通过服务器启动参数或环境变量配置：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| match timeout | 60s | 队列等待超时 |
| room expiry | 30min | 房间有效期 |
| cooldown | 10s | 请求冷却期 |
| rate limit | 20/h | 每 IP 小时限制 |
| max queue | 100 | 最大队列长度 |
| block duration | 24h | 封禁时长 |
| max extensions | 3 | 最大延时次数 |
| --disable-random-match | false | 禁用随机配对功能 |

**禁用功能：** 如果不需要随机配对，可通过 `--disable-random-match` 启动参数完全禁用该功能。
