# Arthas 路线图

> 更新：2026-05-12  
> 目标：多人实时在线页面（同屏 + 移动 + 沟通）  
> 架构：事件驱动（非 Tick Loop）  
> 技术栈：Go · WebSocket · MessagePack · PixiJS · WebGL · React · Vite

---

| 模块 | 状态 |
|------|------|
| 技术选型 & 架构设计 | ✅ 完成 |

| WebSocket 连接 | 🔨 进行中 |
| 多人移动同步 | 🔨 进行中 |
| 实时沟通 | ⏳ 待开始 |

## Phase 1：实时同步 ← 当前

```
目标：多人同屏、移动同步、事件驱动架构跑通
时间：1-2 周
```

- [ ] WebSocket 连接 + Welcome 握手 + 心跳
- [ ] PixiJS 渲染本地玩家（色块 + 名称）
- [ ] WASD 移动 + 乐观更新
- [ ] 服务器事件驱动：收到 Move 即广播
- [ ] 玩家加入/离开生命周期
- [ ] 基础 HUD（在线人数、连接状态）

**Done when：** 两个浏览器窗口互相可见、移动实时同步

---

## Phase 2：实时沟通

```
目标：用户之间能发消息、打招呼
时间：3-5 天
```

- [ ] 文字输入 → ChatMessage → 服务器广播
- [ ] 角色头顶气泡渲染（2s 淡出）
- [ ] 预设表情快捷键
- [ ] 在线玩家列表 + 昵称输入

**Done when：** 发消息其他人实时看到气泡

---

## Phase 3：部署 & 压测

```
目标：公网可用，验证稳定性
时间：3-5 天
```

- [ ] Vercel 部署前端
- [ ] HF Spaces Docker 部署后端
- [ ] 公网 WSS 连通验证
- [ ] 10 人同时在线压测
- [ ] 带宽 / 延迟 / 帧率基准数据

**Done when：** 分享链接给朋友，能正常使用

---

## 风险
