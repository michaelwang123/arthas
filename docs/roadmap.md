## Phase 1：连接 + 房间 ← 当前

```
目标：WebSocket 连接 + 房间创建/加入/销毁
时间：1 周
```

- [ ] WSS 连接 + 心跳保活
- [ ] 创建房间 → 生成 roomId
- [ ] 加入房间 → 验证 roomId → 返回成员列表
- [ ] 离开 → 广播 + 空房间销毁
- [ ] 首页 UI（创建/加入）

**Done when：** 两个窗口通过 roomId 进入同一房间

---

## Phase 2：端到端加密

```
目标：消息加密传输，服务器只见密文
时间：1 周
```

- [ ] Web Crypto API 生成 AES-256 roomKey
- [ ] 密钥编码到分享码 `roomId:base64url(key)`
- [ ] 发送消息：明文 → AES-GCM 加密 → 密文 + IV
- [ ] 服务器：原样转发密文
- [ ] 接收消息：密文 → AES-GCM 解密 → 明文
- [ ] 验证：服务器日志中无明文

**Done when：** 抓包/服务器日志只能看到密文，客户端正常显示明文

## 风险

| 风险 | 缓解 |
|------|------|
| HF Spaces WS 不稳定 | Phase 4 验证；备选 Railway / Fly.io |
| Web Crypto API 兼容性 | 现代浏览器全支持；不支持 IE |
| 密钥分享安全 | 依赖用户通过安全渠道分享（同 Signal 模式） |
| 并发瓶颈 | Go goroutine 天然高并发 |
