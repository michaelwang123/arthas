# Arthas 路线图

> 更新：2026-05-14  
> 定位：加密版 AirDrop + 临时聊天 — 安全交换信息，用完即走  
> 架构：事件驱动，服务器纯中转（零知识）  
> 加密：Web Crypto API + AES-256-GCM  
> 技术栈：Go · WebSocket · MessagePack · React · Vite

---

## 产品定位

```
Arthas ≠ Signal 的替代品（Signal 做长期通信）
Arthas = "我需要和某人安全地交换一些信息，用完即走"

核心价值：
  • 无需注册，打开即用
  • 端到端加密，服务器零知识
  • 阅后即焚，房间销毁密文消失
  • 轻量自托管，一行命令部署
```

## Phase 6：差异化功能

```
目标：形成竞争壁垒，让人选择 Arthas 而非其他工具
时间：1 个月
优先级：🟡 中
```

### 6.1 加密文件分享 ⭐ 最推荐

```
用户选择文件 → 客户端 AES-GCM 加密 → 上传密文
→ 服务器临时存储密文（房间销毁时删除）
→ 接收方下载密文 → 客户端解密 → 保存文件
```

- [ ] 支持图片/文件（限制 10MB）
- [ ] 图片内联预览（加密缩略图）
- [ ] 下载进度条
- [ ] 服务器只存密文，无法查看内容
- [ ] 房间销毁时自动清理文件

### 6.2 房间密码保护

- [ ] 创建房间时可选设置密码
- [ ] 加入时需要分享码 + 密码
- [ ] 防止分享码意外泄露后被陌生人加入

### 6.3 消息回复/引用

- [ ] 滑动/长按消息 → 引用回复
- [ ] 引用内容也是加密的
- [ ] 点击引用跳转到原消息

### 6.4 "阅后即焚"增强模式

- [ ] 可选：消息阅读后 N 秒自动从屏幕消失
- [ ] 纯客户端实现（服务器不参与）
- [ ] 创建房间时选择模式（普通/阅后即焚）

### 6.5 消息反应 (Reactions)

- [ ] 双击消息添加 emoji 反应
- [ ] 反应数据加密传输
- [ ] 显示谁添加了什么反应

**Done when：** 有一个"杀手功能"让用户主动推荐给朋友

## Phase 8：安全升级

```
目标：从"够用的安全"到"专业级安全"
时间：持续迭代
优先级：🔵 低（当前方案已足够安全）
```

| 升级 | 复杂度 | 收益 | 优先级 |
|------|--------|------|--------|
| 加密 typing 状态 | 低 | 减少元数据泄露 | P1 |
| 消息签名 (Ed25519) | 中 | 防服务器伪造消息 | P2 |
| SAS 验证 (Short Auth String) | 中 | 验证对方身份，防中间人 | P2 |
| 密钥轮换 (踢人后) | 中 | 被踢成员无法解密后续消息 | P2 |
| Double Ratchet (前向保密) | 高 | 密钥泄露不影响历史消息 | P3 |
| WebRTC P2P (可选) | 高 | 完全绕过服务器 | P3 |

**Done when：** 通过第三方安全审计

## 战略原则

### ✅ 坚持做的

| 原则 | 理由 |
|------|------|
| 无需注册 | 核心卖点，降低使用门槛 |
| 阅后即焚 | 核心卖点，差异化定位 |
| 服务器零知识 | 安全基石，不可妥协 |
| 轻量简洁 | 用完即走的工具，不是社交平台 |
| 开源透明 | 建立信任，安全可审计 |

### ❌ 不做的

| 反模式 | 理由 |
|--------|------|
| 用户注册/账号体系 | 杀死"无需注册"核心价值 |
| 消息持久化/历史记录 | 杀死"阅后即焚"核心价值 |
| 原生 App (iOS/Android) | PWA 足够，维护成本太高 |
| 过度工程化后端 | 它就是个 relay，保持简单 |
| 急着加 Double Ratchet | 对临时聊天收益不大，复杂度极高 |
| 社交功能（好友/群组/动态） | 偏离定位，变成另一个 IM |

## 竞品分析

| 产品 | 定位 | Arthas 优势 |
|------|------|-------------|
| Signal | 长期加密通信 | 无需注册，更轻量 |
| Telegram Secret Chat | 加密聊天 | 无需注册，完全开源 |
| PrivNote | 加密便签 | 实时聊天，多人 |
| Yopass | 加密分享 | 实时聊天，交互式 |
| Briar | P2P 加密 | 无需安装 App，Web 即用 |

**Arthas 的独特位置：** Web 端 + 无注册 + 实时多人 + E2EE + 阅后即焚
