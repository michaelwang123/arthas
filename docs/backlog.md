# Arthas Backlog

> 目标：端到端加密实时聊天室  
> 服务器纯中转，无法读取消息内容  
> 创建临时 Group → 分享密钥 → 加密通信

---

## 验收标准

- [ ] 创建房间，获得包含加密密钥的分享码
- [ ] 伙伴凭分享码加入房间
- [ ] 消息端到端加密（AES-256-GCM），服务器只转发密文
- [ ] 房间内实时聊天，解密后正常显示
- [ ] 服务器日志/内存中无明文消息
- [ ] 所有人离开后房间销毁
- [ ] 公网 WSS (TLS 1.3) 可访问

---

## 高优先级

### 1. WebSocket 连接
- WSS 连接 + TLS 传输加密
- 心跳保活（25s Ping/Pong）
- 断线检测 + 自动重连
- 连接状态 UI

### 2. 房间系统
- 创建房间 → 服务器生成 roomId
- 加入房间 → 验证 roomId 存在 → 加入
- 离开 → 广播 MemberLeft → 空房间销毁
- 房间人数上限

### 3. 端到端加密
- Web Crypto API 生成 AES-256 roomKey
- 密钥编码到分享码：`roomId:base64url(roomKey)`
- 发送：明文 → AES-GCM 加密 → 发送密文 + IV
- 接收：密文 + IV → AES-GCM 解密 → 明文
- 服务器只做密文原样转发

### 4. 实时聊天
- 加密消息发送 → 服务器转发 → 接收端解密显示
- 消息列表实时更新
- 在线成员列表
- "正在输入" 状态

---

## 中优先级

### 5. 分享机制
- 一键复制分享码（含加密密钥）
- 生成分享链接：`/join/{roomId}:{key}`
- 链接打开自动解析并加入

### 6. UI 体验
- 首页：创建/加入入口
- 聊天界面：消息流 + 输入框 + 成员侧栏
- 加密状态指示（🔒 图标）
- 暗色主题 + 响应式

### 7. 部署
- Vercel 前端（HTTPS）
- HF Spaces Docker 后端（WSS）
- 公网加密通信验证

---

## 低优先级

### 8. 安全增强
- 消息频率限制（防刷屏）
- 消息长度限制
- roomId 有效性校验
- 连接数限制

### 9. 体验打磨
- 消息通知音效
- 表情/Emoji 输入
- 消息时间戳显示
- 移动端适配
