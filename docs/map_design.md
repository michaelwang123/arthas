# 世界地图与关卡设计

> 基于 2D PixiJS + WebSocket 的技术约束设计  
> 地图采用"区域实例"模式，非无缝大世界

---

## 设计原则

| 原则 | 说明 |
|------|------|
| 区域化 | 世界分为独立区域（Zone），每个区域是一个服务器房间 |
| 渐进加载 | 玩家进入新区域时按需加载资源 |
| 冲突密度 | 越靠近中心，PvP 密度越高 |
| 叙事引导 | 地图布局本身讲述故事（从安全→危险→未知） |
| 性能优先 | 单区域同时在线上限 50–100 人，超出则开新实例 |

## 区域详细设计

### 一、永霜（Everfrost）— 虚空誓约领地

#### 1.1 虚空王座（The Hollow Throne）

| 属性 | 描述 |
|------|------|
| 类型 | 阵营主城（安全区） |
| 氛围 | 永恒的暴风雪中矗立的黑色冰晶宫殿，天空呈深紫色 |
| 功能 | NPC 交互、商店、任务领取、阵营大厅 |
| PvP | 禁止 |

**视觉要素**：
- 黑色冰晶建筑，内部有紫色能量脉络流动
- 永不停歇的暴风雪粒子效果
- 远处可见虚空之王的巨大剪影（静态背景）
- 地面有冻结的士兵雕像（曾经的入侵者）

**关键 NPC**：
- 薇克萨拉（任务大厅）
- 低语者（新手引导区）
- 虚空锻造师（装备强化）

---

#### 1.2 冰封矿脉（Frozen Veins）

| 属性 | 描述 |
|------|------|
| 类型 | PvE 资源区 |
| 氛围 | 巨大的地下冰洞，墙壁中嵌有发光的源石碎片 |
| 功能 | 资源采集、小型怪物刷新、日常任务 |
| PvP | 仅限对敌对阵营（进入此区域的敌方玩家） |

**设计要点**：
- 多层洞穴结构，越深层资源越好但怪物越强
- 源石碎片矿点每 5 分钟刷新
- 深层有稀有矿点，刷新时全区域广播（吸引 PvP）
- 环境危害：周期性的"虚空脉冲"，站在特定区域会持续掉血

---

### 二、灰野（Ashveil）— 灰烬自由军领地

#### 2.1 铁避风港（Iron Haven）

| 属性 | 描述 |
|------|------|
| 类型 | 阵营主城（安全区） |
| 氛围 | 由战争废墟拼凑而成的要塞城市，烟囱林立，蒸汽弥漫 |
| 功能 | NPC 交互、商店、任务领取、工坊系统 |
| PvP | 禁止 |

**视觉要素**：
- 废金属和木材搭建的多层建筑
- 到处是冒烟的管道和简陋的机械装置
- 中心广场有一面巨大的"自由旗"（破布拼成）
- 背景音：锤击声、人群喧嚣、偶尔的爆炸

**关键 NPC**：
- 铁帅凯尔（指挥部）
- 老烟（城门口的瞭望台）
- 废墟工匠（装备制造/改造）

---

#### 2.2 新生林（The Newgrowth）

| 属性 | 描述 |
|------|------|
| 类型 | PvE 特殊区域 |
| 氛围 | 灰野废墟中唯一的绿色区域，翠族正在培育的新森林 |
| 功能 | 治愈物品采集、翠族任务线、休息回复区 |
| PvP | 禁止（翠族结界保护） |

**设计要点**：
- 进入此区域自动获得缓慢生命回复
- 莉拉·荆织的任务线在此展开
- 玩家可以"种植"——投入资源帮助森林扩张（长期阵营建设目标）
- 如果阵营战中灰烬自由军失利，新生林会"枯萎"（视觉反馈）

---

### 三、余晖（Dawnrest）— 黎明遗脉领地

#### 3.1 光明圣所（Sanctuary of Light）

| 属性 | 描述 |
|------|------|
| 类型 | 阵营主城（安全区） |
| 氛围 | 白色大理石与金色装饰的神殿城市，永远沐浴在温暖的光芒中 |
| 功能 | NPC 交互、商店、任务领取、祈祷系统（buff） |
| PvP | 禁止 |

**视觉要素**：
- 白色石材建筑，金色穹顶
- 空中漂浮的光球（源石残余能量）
- 中心是巨大的"凯恩纪念碑"——圣王堕落前的雕像
- 柔和的金色光线从天空洒下

**关键 NPC**：
- 瑟拉菲娜（大神殿）
- 长老·晶忆（图书馆）
- 光铸匠人（装备附魔）

---

#### 3.2 封印大教堂（The Sealed Cathedral）

| 属性 | 描述 |
|------|------|
| 类型 | 高级副本（Raid） |
| 氛围 | 被封印的古老教堂，内部时间停滞，保存着凯恩堕落前最后的记忆 |
| 功能 | 4–8 人组队副本，主线剧情推进 |
| PvP | 禁止（副本内） |

**设计要点**：
- 需要特定声望等级才能进入
- 内部是"记忆空间"——玩家体验凯恩堕落前的最后时刻
- Boss 是凯恩记忆中的"恐惧具象化"
- 通关奖励：关于净化/弑王的关键信息 + 稀有装备

---

### 四、争夺区域（Contested Zones）

#### 4.1 碎冰峡谷（Shattered Glacier）

| 属性 | 描述 |
|------|------|
| 类型 | 北部争夺区（永霜↔灰野边境） |
| 氛围 | 巨大的冰川碎片漂浮在虚空能量海上，玩家在冰块间跳跃战斗 |
| 功能 | 开放 PvP + 源石碎片争夺 |
| PvP | 全面开放 |

**设计要点**：
- 地形：漂浮冰块平台，部分会周期性沉没
- 3 个源石碎片采集点，每 10 分钟刷新
- 占领机制：在采集点附近停留 30 秒即可"占领"，占领期间本阵营获得采集加速
- 环境危害：虚空能量海（掉落即死）

---

#### 4.2 裂隙之桥（The Rift Bridge）

| 属性 | 描述 |
|------|------|
| 类型 | 核心 PvP 区（三方交汇点） |
| 氛围 | 连接三块大陆的巨大古桥废墟，桥面断裂但仍可通行 |
| 功能 | 三阵营混战 + 高价值资源 |
| PvP | 全面开放（三方混战） |

**设计要点**：
- 世界地图的物理中心，三条路分别通向三个阵营
- 桥中心有"源石涌泉"——每小时刷新一次的超高价值资源
- 涌泉刷新前 5 分钟全服广播，吸引三方玩家聚集
- 地形优势：桥面狭窄，有利于防守方
- 这是游戏中最激烈的 PvP 热点

---

#### 4.3 焦土平原（Scorched Plains）

| 属性 | 描述 |
|------|------|
| 类型 | 资源争夺区（灰野外围） |
| 氛围 | 被战火烧焦的广阔平原，散落着战争机械残骸 |
| 功能 | 大规模资源采集 + 中等 PvP |
| PvP | 开放（但区域大，可以避战） |

**设计要点**：
- 最大的开放区域，适合"不想打架只想采集"的玩家
- 资源点分散且数量多，降低冲突密度
- 偶尔刷新"战争遗物"——高价值可拾取物品
- 有 NPC 商队路过（可保护获得奖励，或劫掠获得物资）

---

#### 4.4 金色原野（Golden Fields）

| 属性 | 描述 |
|------|------|
| 类型 | 南部争夺区（余晖↔灰野边境） |
| 氛围 | 曾经的农田现在长满金色野草，废弃的村庄散布其中 |
| 功能 | 中等 PvP + 探索/剧情任务 |
| PvP | 开放 |

**设计要点**：
- 视觉上最"美"的争夺区——金色草海、夕阳、废弃风车
- 隐藏大量剧情触发点（废弃村庄中的日记、信件）
- 源石碎片埋在地下，需要"探测"才能找到（增加探索感）
- 偶尔出现"记忆幻影"——黎明纪时代的幽灵重演历史片段

---

### 五、特殊区域

#### 5.1 废墟星辉塔（Ruins of Stellaris）

| 属性 | 描述 |
|------|------|
| 类型 | 中立副本（4 人） |
| 氛围 | 漂浮在空中的塔楼残骸，内部充满失控的魔法能量 |
| 功能 | PvE 副本 + 世界观揭示 + 稀有掉落 |
| PvP | 禁止（副本内） |

**设计要点**：
- 所有阵营都可进入（中立区域）
- 内部是"扭曲空间"——重力异常、时间碎片
- Boss 是失控的魔法实验体
- 通关可获得"星辉碎片"——用于解锁世界观文本
- 艾洛恩（中立 NPC）在入口处提供引导

---

#### 5.2 源石陨坑（The Corestone Crater）

| 属性 | 描述 |
|------|------|
| 类型 | 周期性世界事件区域 |
| 氛围 | 世界中心的巨大陨坑，源石能量从地底喷涌而出 |
| 功能 | 全服事件（虚空潮汐 / 源石喷发） |
| PvP | 事件期间全面开放 |

**设计要点**：
- 平时关闭，仅在特定事件期间开放
- **源石喷发事件**（每周一次）：大量源石碎片从陨坑喷出，三阵营争抢
- **虚空潮汐事件**（每月一次）：虚空怪物从陨坑涌出，三阵营需暂时合作击退
- 事件期间此区域是全服焦点，奖励最丰厚
- 虚空潮汐 Boss 击杀后掉落赛季限定装备

---

#### 5.3 深渊海沟（The Abyss）— v2.0 内容

| 属性 | 描述 |
|------|------|
| 类型 | 未来版本区域 |
| 氛围 | 大陆边缘的深海区域，渊族的领地 |
| 功能 | 新种族解锁 + 新剧情线 |
| PvP | 待定 |

**预留设计**：
- v2.0 开放，需完成深海使者任务线
- 水下战斗机制（新的移动/战斗规则）
- 揭示渊族掌握的源石秘密
- 引入"第三种威胁"——比虚空更古老的存在

## 地图技术实现要点

### 区域切换

```
玩家移动到区域边界 → 触发加载动画 → 断开当前区域 WebSocket 房间 
→ 连接新区域房间 → 加载新区域资源 → 玩家出现在新区域入口
```

### 实例管理

- 每个区域有人数上限（安全区 200 人，战斗区 50–100 人）
- 超出上限自动创建新实例
- 同阵营玩家优先分配到同一实例
- 组队玩家强制同一实例

### 资源加载策略

- 主城资源预加载（登录时）
- 相邻区域资源预加载（进入当前区域时）
- 远距离区域按需加载
- 所有贴图使用 WebP 格式，Sprite Sheet 打包

### 地图数据结构

```json

  "zoneName": "裂隙之桥",

```
