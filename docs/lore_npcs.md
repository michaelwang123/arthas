# 关键 NPC 角色设定

> 每个阵营设有：领袖、副官/冲突角色、导师、内部对立者  
> 另有中立角色串联主线剧情

---

## 虚空誓约（Hollow Covenant）

### 薇克萨拉·无缚者（Vexara the Unbound）— 阵营领袖

| 属性 | 描述 |
|------|------|
| 种族 | 影族（Umbral） |
| 职位 | 虚空第一将军，虚空之王的代言人 |
| 年龄 | 约 380 岁 |
| 外貌 | 银白瞳孔，半身已被虚空能量晶化为深紫色，左臂为纯粹的暗能量构成 |

**背景**：大分裂时期第一个主动拥抱虚空力量的影族。她认为虚空并非腐蚀，而是"进化"。在虚空之王沉默后，她实际掌控着誓约的日常运作。

**性格**：冷静、理性、极度自信。不像典型反派那样疯狂，而是真诚地相信虚空是更高形态的存在。

**玩家互动**：
- 虚空誓约玩家的主要任务发布者
- 会根据玩家表现给予不同程度的"虚空赐福"（增益 buff）
- 隐藏剧情：她其实能感知到虚空之王体内凯恩的意识波动

**经典台词**：
> "自由意志？那不过是弱者为自己的无力找的借口。真正的自由，是拥有碾碎一切枷锁的力量。"

### 塞隆·灰谷（Theron Ashvale）— 冲突角色

| 属性 | 描述 |
|------|------|
| 种族 | 人族（Human） |
| 职位 | 虚空骑士团副团长 |
| 年龄 | 34 岁 |
| 外貌 | 曾经的黎明遗脉骑士铠甲被虚空能量侵蚀为黑金色，右眼已变为紫色 |

**背景**：原黎明遗脉精锐骑士，在一次虚空潮汐中被俘。本应被处决，但虚空之王亲自"赦免"了他——没人知道为什么。此后他"自愿"加入誓约，但内心深处仍有挣扎。

**性格**：沉默寡言，执行任务时冷酷无情，但偶尔会在战场上放走平民。

**玩家互动**：
- 给玩家布置"灰色地带"任务（如：摧毁一个村庄的防御，但可以选择是否警告村民）
- 玩家选择会影响他的后续剧情走向
- 隐藏剧情线：帮助他恢复记忆，可能触发叛逃事件

### 低语者（The Whisperer）— 导师

| 属性 | 描述 |
|------|------|
| 种族 | 未知（疑似堕落晶族） |
| 职位 | 新成员引导者 |
| 年龄 | 未知 |
| 外貌 | 一团漂浮的暗紫色晶体碎片，中心有微弱的脉动光芒，以心灵感应交流 |

**背景**：没人知道低语者的真实身份。它漂浮在永霜的入口处，引导每一个新加入誓约的觉醒者。它的声音温柔而诱惑，总是说出你最想听的话。

**玩家互动**：
- 新手教程 NPC
- 提供虚空力量的使用指导
- 随着玩家等级提升，低语者的话语会越来越"真实"——暗示它可能是凯恩残存意识的碎片

### 玛拉卡尔·逆光（Malachar the Inverse）— 内部对立者

| 属性 | 描述 |
|------|------|
| 种族 | 辉族（Solari，堕落） |
| 职位 | 虚空教廷大主教 |
| 年龄 | 约 420 岁 |
| 外貌 | 金色皮肤上布满黑色裂纹，光晕变为吞噬光线的"逆光"，华丽的黑金法袍 |

**背景**：曾是黎明纪最后一代辉族大祭司。大分裂时他选择了虚空，但并非出于信仰——而是出于野心。他认为虚空之王不配拥有源石之力，真正的王应该是他。

**性格**：傲慢、阴险、善于操纵。表面忠诚，暗中培植自己的势力。

**玩家互动**：
- 高等级任务线的暗线 BOSS
- 会试图拉拢高声望玩家加入他的"内部改革"
- v2.5 版本的阵营内战核心触发者

## 黎明遗脉（Dawn Remnant）

### 瑟拉菲娜·光守（Seraphina Lightward）— 阵营领袖

| 属性 | 描述 |
|------|------|
| 种族 | 辉族（Solari） |
| 职位 | 光明大祭司，净化派领袖 |
| 年龄 | 约 290 岁 |
| 外貌 | 纯金色长发，瞳孔如液态黄金，身着白金祭司袍，周身光晕明显 |

**背景**：阿萨隆王室的远亲，自幼被培养为源石祭司。她坚信凯恩的灵魂可以被净化拯救，为此投入了两百年的研究。她的信念是黎明遗脉团结的基石，但也是最大的弱点——如果净化被证明不可能呢？

**性格**：温和但坚定，有母性般的包容力，但在涉及凯恩的问题上绝不妥协。

**玩家互动**：
- 黎明遗脉玩家的主要任务发布者
- 提供净化相关的主线任务
- 会在关键剧情节点询问玩家立场（净化 vs 弑王）

**经典台词**：
> "他为了拯救我们所有人而堕落。我们怎能以毁灭来回报他的牺牲？"

---

### 奥德里克·石心指挥官（Commander Aldric Stoneheart）— 冲突角色

| 属性 | 描述 |
|------|------|
| 种族 | 人族（Human） |
| 职位 | 黎明军团总指挥 |
| 年龄 | 52 岁 |
| 外貌 | 满脸伤疤的老兵，灰色短发，穿着磨损但保养精良的银色铠甲 |

**背景**：经历过两次虚空潮汐的老兵，亲眼看着无数战友被虚空腐蚀。他尊重瑟拉菲娜，但内心深处认为"净化"是不切实际的幻想。他没有公开反对，而是默默为"最坏情况"做准备。

**性格**：务实、沉稳、有军人的纪律性。对士兵极好，但对"理想主义"越来越不耐烦。

**玩家互动**：
- 军事任务线的核心 NPC
- 会给玩家布置"实际"任务（侦察、防御、物资运输）
- 高声望后会透露他的真实想法，引导玩家进入弑王派剧情线

### 长老·晶忆（Elder Crystallis）— 导师

| 属性 | 描述 |
|------|------|
| 种族 | 晶族（Crystalline） |
| 职位 | 余晖图书馆守护者 |
| 年龄 | 约 2800 岁（黎明纪中期诞生） |
| 外貌 | 3 米高的人形晶体，大部分身体已半透明，内部可见流动的金色记忆光流 |

**背景**：星辉塔时代的学者，亲历了黎明纪的黄金时代。大分裂时被埋在废墟下数百年，被黎明遗脉挖出后成为最珍贵的"活历史"。但他的记忆正在缓慢流失——每分享一段记忆，就会永远失去它。

**性格**：缓慢、深思、偶尔会混淆过去和现在。说话时会停顿很久。

**玩家互动**：
- 世界观/背景故事的主要讲述者
- 玩家可以"请求记忆"——获得关于远古事件的剧情片段
- 每次请求都会让他变得更"模糊"，增加紧迫感

### 拉弗斯·弑王者（Ravus the Kingslayer）— 内部对立者

| 属性 | 描述 |
|------|------|
| 种族 | 人族（Human） |
| 职位 | 弑王派领袖，"终焉骑士团"团长 |
| 年龄 | 41 岁 |
| 外貌 | 黑发红瞳（源石碎片副作用），穿着刻有"终焉"符文的黑色铠甲 |

**背景**：瑟拉菲娜的前学生，曾是最虔诚的净化派信徒。直到他在一次任务中亲眼看到虚空之王的真实力量——那一刻他确信，净化是不可能的。此后他公开决裂，建立了弑王派，主张"唯有毁灭虚空之王，才能终结这一切"。

**性格**：激进、有感染力、真诚但偏执。他不是坏人，只是选择了更残酷的道路。

**玩家互动**：
- 弑王派任务线的核心 NPC
- 与瑟拉菲娜形成对立选择
- v2.5 版本可能引发黎明遗脉内战

## 灰烬自由军（Ashborn）

### 铁帅·凯尔（Iron Marshal Kael）— 阵营领袖

| 属性 | 描述 |
|------|------|
| 种族 | 人族（Human） |
| 职位 | 灰烬联盟最高统帅 |
| 年龄 | 38 岁 |
| 外貌 | 棕色皮肤，剃光头，左脸有烧伤疤痕，穿着由废墟金属拼凑的铠甲 |

**背景**：灰野废墟中长大的孤儿，靠拳头和智慧统一了三个最大的自由城邦。他不信神、不信王、只信"人能掌握自己的命运"。他的魅力在于：他是第一个让灰野人相信"我们不是难民，我们是自由人"的领袖。

**性格**：粗犷、直率、有黑色幽默感。对手下极度忠诚，但对背叛者绝不留情。

**玩家互动**：
- 灰烬自由军玩家的主要任务发布者
- 任务风格偏"生存"和"建设"（收集资源、建立据点、保护商队）
- 会根据玩家贡献给予"自由军衔"

**经典台词**：
> "神创造了我们，然后把世界炸成了碎片。王试图拯救我们，然后变成了怪物。所以——去他妈的神和王。我们自己来。"

### 莉拉·荆织（Lyra Thornweave）— 冲突角色

| 属性 | 描述 |
|------|------|
| 种族 | 翠族（Verdant） |
| 职位 | 灰野治愈者公会会长 |
| 年龄 | 约 160 岁 |
| 外貌 | 深绿色皮肤，发丝为活的藤蔓（会随情绪变化），身着树皮编织的长袍 |

**背景**：根守派翠族的代表，留在灰野试图让被毁的森林重生。她加入自由军是因为凯尔承诺保护她的"新生林"，但她对战争本身深感厌恶。她的治愈能力使她成为灰野最珍贵的存在——也是最大的目标。

**性格**：温柔但有底线，不愿伤害任何生命，但为了保护森林可以变得极度危险。

**玩家互动**：
- 治愈/制药相关任务的核心 NPC
- 提供独特的自然系增益物品
- 隐藏剧情：她的母树其实在永霜境内，这是她最大的秘密和弱点

### 老烟（Old Smoke）— 导师

| 属性 | 描述 |
|------|------|
| 种族 | 人族（Human） |
| 职位 | 自由军首席斥候（退役） |
| 年龄 | 67 岁 |
| 外貌 | 瘦小干瘪的老头，永远叼着一根自制烟斗，穿着打满补丁的皮甲 |

**背景**：灰野最老的拾荒者之一，声称自己"走过灰野每一寸废墟"。没人知道他的真名，因为他总是烟不离手所以被叫"老烟"。他知道每一条暗道、每一个隐藏的物资点、每一个危险区域的规律。

**性格**：话多、爱吹牛、但关键时刻极度可靠。对新人有种老父亲般的关怀。

**玩家互动**：
- 新手教程 NPC + 探索任务发布者
- 教授玩家地图机制（安全路线、资源点刷新规律）
- 高等级后会透露他年轻时的秘密——他曾是阿萨隆帝国的皇家斥候

### 军阀·格拉克斯（Warlord Grax）— 内部对立者

| 属性 | 描述 |
|------|------|
| 种族 | 人族（Human） |
| 职位 | "铁拳城"城主，自由军最大的内部反对派 |
| 年龄 | 45 岁 |
| 外貌 | 巨大壮硕，满身肌肉和伤疤，右臂装有源石碎片驱动的机械义肢 |

**背景**：曾是凯尔的战友，一起打下了灰野的自由。但他们对"自由之后怎么办"产生了根本分歧——凯尔要建设，格拉克斯要征服。他认为灰烬自由军应该趁两大阵营互相消耗时，吞并双方领土。

**性格**：暴躁、直接、有军事天才但缺乏政治智慧。不是坏人，只是信奉"进攻是最好的防守"。

**玩家互动**：
- 高等级 PvP 任务线的触发者
- 会试图拉拢高战力玩家加入他的"征服计划"
- 玩家选择支持凯尔还是格拉克斯会影响阵营发展方向

## 中立 / 跨阵营角色

### 最后的星辉学者·艾洛恩（Elowen, Last Scholar of Stellaris）

| 属性 | 描述 |
|------|------|
| 种族 | 辉族/人族混血 |
| 职位 | 流浪学者 |
| 年龄 | 约 180 岁 |
| 外貌 | 金色与黑色交织的长发，一只眼为金色一只为紫色，穿着破旧的星辉塔学者袍 |

**背景**：星辉塔毁灭时唯一的幸存者（或者说，她声称如此）。她游走于三大阵营之间，向所有人出售"知识"——关于源石、关于凯恩、关于原初存在。没人完全信任她，但没人能忽视她掌握的信息。

**真实身份（隐藏）**：她可能是塔尔诺斯（平衡之神）意识的碎片化身——第四种力量的代理人。

**玩家互动**：
- 主线剧情的关键推动者
- 出现在所有阵营的特定地点，提供跨阵营视角的任务
- 她的任务往往揭示世界观的深层真相
- 完成她的全部任务线是解锁 v3.0 "苏醒"剧情的前置条件

**经典台词**：
> "你想知道真相？真相是——凯恩的仪式并没有失败。它完美地按照某人的计划执行了。问题是：那个'某人'是谁？"
