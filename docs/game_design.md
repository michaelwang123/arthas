# 「Arthas」游戏设计概要

> 暗黑奇幻 · 堕落王朝 · 在线多人网页游戏

---

## 游戏定位

| 维度 | 描述 |
|------|------|
| 类型 | 在线多人网页游戏（2D） |
| 主题 | 暗黑奇幻 · 堕落王朝 |
| 目标用户 | 北美 / 欧洲玩家 |
| 平台 | 网页浏览器（PC 优先） |
| 视觉风格 | 2D PixiJS，暗黑手绘/像素风 |

---

## 核心玩法循环

```
选择阵营 → 探索地图 → 争夺源石碎片 → 提升角色力量 → 阵营对抗/领地战 → 赛季结算
```

---

## 叙事与机制映射

| 叙事元素 | 对应玩法 | 说明 |
|----------|----------|------|
| 三大阵营 | 阵营选择 + PvP | 玩家选阵营，参与阵营领地战 |
| 源石碎片散落 | 资源点争夺 | 地图上的核心 PvP 循环目标 |
| 碎片觉醒者 | 玩家角色设定 | 解释为何人人都有力量 |
| 虚空潮汐 | 周期性 PvE 事件 | Boss Raid / 全服防御战 |
| 凯恩的双重人格 | 长线剧情更新 | 版本更新的叙事钩子 |
| 阵营内部矛盾 | 支线任务 / 声望系统 | 净化派vs弑王派等选择 |
| 源石碎片能力 | 角色成长系统 | 碎片赋予不同能力/天赋 |

## 阵营设计

### 虚空誓约（Hollow Covenant）

- **玩家画像**：喜欢力量感、暗黑美学、不介意"反派"定位的玩家
- **阵营优势**：单体战斗力强，暴发型
- **阵营劣势**：协作能力弱，长期会有"腐蚀"debuff 机制

### 黎明遗脉（Dawn Remnant）

- **玩家画像**：喜欢正统叙事、团队协作、守护者角色的玩家
- **阵营优势**：团队增益强，防御型
- **阵营劣势**：内部派系选择会影响可用技能路线

### 灰烬自由军（Ashborn）

- **玩家画像**：喜欢自由度、策略博弈、不站队的玩家
- **阵营优势**：灵活性高，可与任意阵营临时结盟
- **阵营劣势**：基础资源获取较难，需要更多策略

## 商业化方向

| 模式 | 说明 |
|------|------|
| 赛季通行证 | 每赛季（虚空潮汐周期）推出付费通行证 |
| 外观商城 | 武器/角色皮肤，不影响数值 |
| 阵营捐献 | 阵营战期间可付费加速阵营进度（需平衡） |

## 技术约束下的设计原则

> 详见 [req_draw.md](../req_draw.md)

1. **轻量优先**：所有机制设计需考虑 WebSocket 带宽和服务器 Tick Rate 限制
2. **异步容忍**：核心玩法需在 100–200ms 延迟下仍有良好体验
3. **低资源运行**：服务器逻辑不做每帧模拟，只做关键校验
4. **渐进加载**：地图/资源按需加载，首屏控制在 3 秒内
